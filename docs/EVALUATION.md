# Evaluation — PROBAHO (প্রবাহ)

> **These metrics are computed on synthetic data and validate the pipeline only.** They demonstrate that the forecasting and evaluation code functions correctly, not that the models are accurate for real-world supply chains.

---

## 1. Overview

The evaluation pipeline runs all forecasting models over the synthetic dataset generated by `seed/generator.py` (seed=42) and reports accuracy metrics per model, per medicine, and per facility.

**To regenerate:**

```bash
cd ai-service
python -m seed.generator          # generate synthetic data
python -m scripts.run_evaluation   # run evaluation, writes evaluation/report.json
```

Results are saved to `ai-service/evaluation/report.json`.

---

## 2. Models Evaluated

| Model | Description |
|-------|-------------|
| Naive | Repeats the last observed value |
| Moving Average (k=7) | 7-day rolling mean |
| Exponential Smoothing | Single-parameter adaptive smoothing |
| Holt-Winters (Additive) | Seasonal model with level + trend + weekly seasonality |

---

## 3. Metrics

| Metric | Formula | Description |
|--------|---------|-------------|
| MAE | `(1/n) Σ |y - ŷ|` | Mean Absolute Error — average error in original units |
| RMSE | `√((1/n) Σ (y - ŷ)²)` | Root Mean Squared Error — penalises large errors |
| WAPE | `Σ|y - ŷ| / Σ|y|` | Weighted Absolute Percentage Error — scale-free |

All metrics are computed via **rolling-origin cross-validation** to avoid train/test leakage.

## 5. Per-Medicine Breakdown

The evaluation reports metrics for each of the 5 tracer medicines:

| Medicine | Expected Pattern |
|----------|-----------------|
| Paracetamol 500mg | Steady with slight weekly variation |
| Amoxicillin 500mg | Steady consumption |
| Metformin 500mg | Chronic-disease driven, stable |
| Omeprazole 20mg | Moderate, stable |
| ORS Sachets | Strong monsoon-season spike (Jun–Sep) |

ORS is the most challenging to forecast due to its pronounced seasonality, and is where Holt-Winters is expected to outperform simpler baselines.

---

## 6. Per-Facility Breakdown

Metrics are reported for all 6 facilities:

| Facility Type | Expected Characteristics |
|---------------|-------------------------|
| Upazila Health Complex (×3) | Higher volume, more stable demand |
| Community Clinic (×3) | Lower volume, noisier demand |

Community clinics typically show higher WAPE due to lower absolute volumes making percentage errors more volatile.

---

## 7. Interpretation Guidance

1. **Holt-Winters should beat baselines** on medicines with weekly or seasonal patterns, particularly ORS.
2. **Naive may be competitive** for very stable medicines (Metformin) where demand changes little day-to-day.
3. **WAPE < 25%** is the target for the best model on each medicine. This is a synthetic-data benchmark, not a real-world accuracy claim.
4. **High RMSE relative to MAE** suggests occasional large forecast errors — investigate the specific time periods.

---

## 8. Limitations

- All data is synthetic. These metrics validate the code pipeline, not real-world forecast accuracy.
- The seasonal patterns are engineered (e.g., ORS monsoon spike); real seasonality may differ.
- Rolling-origin CV uses a fixed minimum window; different window sizes could yield different results.
- No external regressors (weather, campaigns, holidays) are included in P0 models.
